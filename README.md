# PlataformerGameTemplate

Schema cru do ecossistema plataformgame.

## Estrutura
- `docs/design-system/` — tokens, palette ASCII, sprites
- `docs/game-design/` — combate, progressão, enemies, world
- `docs/principles/` — arquitetura, core/support, scheduler
- `src/core/` — primitives, enums, System base
- `src/support/` — sistemas com GameContext
- `src/entities/` — Entity base
- `src/game/` — Game e Bootstrapper esqueleto
- `src/world/` — World façade
- `src/assets/` — sprites e palettes

## Uso
Este template contém documentação levantada e esqueletos mínimos para iniciar um novo projeto plataforma mantendo os princípios do ecossistema original.
